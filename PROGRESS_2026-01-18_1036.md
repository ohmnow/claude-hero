### 1. Bug Audit & Fixes (ClaudeHero Plugin)

Identified and fixed **13 bugs** across the codebase:

#### Critical (4 fixed)
- **Race condition in cooldown.ts** - Added file-based locking (`/tmp/claude-hero-state.lock`) to prevent concurrent state corruption
- **Hardcoded dev path in loader.ts** - Removed `/Users/chris/cc-projects/...` hardcoded path

- **GitHub client timeout leak in client.ts** - Same fix pattern as above

#### Medium (6 fixed)
- **Unused state variable in hero/hooks.ts** - Removed unused `state` assignment
- **Missing category mappings in index.ts** - Added mappings for `type-safety`, `error-handling`, `documentation`, `production`, `code-quality`
- **Non-null assertion issue in hero/hooks.ts** - Added proper null check for `currentFeatureId`
- **Deduplication bug in rules/index.ts** - Fixed to dedupe by `ruleId` instead of category type
- **Error handling in index.ts** - Improved error logging with stack traces

#### Low (3 fixed)
- **Config double-loading in index.ts** - Reused existing config variable
- **JSON parse error logging in hero/state.ts** - Added debug logging for malformed files
- **Box formatter empty array issue** - Fixed `Math.max(...[])` crash
- **Regex safety in intent-matcher.ts** - Added input length limit (10000 chars) to prevent ReDoS
